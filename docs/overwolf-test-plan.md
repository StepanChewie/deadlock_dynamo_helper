# План тестирования перед сабмитом

Составлен по официальному гайду Overwolf:
<https://dev.overwolf.com/ow-native/guides/test-your-app/how-to-test-your-app/>

Порядок и формулировки проверок — их. Привязка к нашему приложению, конкретные значения и то,
что уже проверено автоматически, — наши.

**Важно перед началом.** Правка `4570c952` заменила несуществующее `default_position` на
`start_position`. До неё Overwolf **игнорировал позиции окон целиком**, то есть оверлей и попап
открывались там, куда их ставил сам. Теперь оверлей впервые появится на **20 px слева, 80 px
сверху**, а попап — на **800 / 180**. Это изменение поведения, и его надо проверить глазами, а не
предполагать, что «раньше же работало».

## 1. Манифест — ✅ проверено автоматически

| Проверка | Как | Статус |
|---|---|---|
| Строгий JSON, без висячих запятых | парсится валидатором | ✅ |
| Соответствие официальной схеме | `yarn workspace @dynamo-lab/overwolf-client check:manifest-schema` | ✅ **валиден** |
| `launcher_icon` < 150 КБ | 26.4 КБ, четыре слоя 16/32/48/256 | ✅ |
| `icon`, `icon_gray` < 30 КБ, 256×256 | 11.6 и 12.5 КБ | ✅ |
| 72 PPI прописан | чанк `pHYs` в каждом PNG | ✅ |
| Флаги рекламы на каждом окне | `block_top_window_navigation`, `popup_blocker`, `mute` | ✅ |
| `launch_events` только для нашей игры | `GameLaunch`, `game_ids: [24482]` | ✅ |

**Что нашла эта проверка** (и почему её стоило прогнать): манифест содержал **три свойства,
которых у Overwolf нет** — `use_in_game_coordinate_system`, `default_position` и `action-name`.
Из-за второго позиции окон не применялись, а наш собственный валидатор и один из тестов читали
именно это мёртвое свойство, то есть выглядели как проверка, ничего не проверяя.

**Остаётся за владельцем:**

- [ ] **`author` и `name` не менялись между версиями.** UID выводится из них и не меняется после
      публикации. Ярлык приложения называется `Statlocker Companion`, а манифест объявляет
      `Dynamo Lab` — **проверить до подачи**.
- [ ] **`minimum-overwolf-version: 0.197.0` полностью раскатан на всех пользователей.** Гайд
      требует убедиться в этом до релиза; из репозитория это не проверить.
- [ ] **`minimum-gep-version`.** Сейчас `305.0`, но код читает `match_outcome`, который приходит
      с GEP **310.2.8**. При 305–310.2.7 поле не придёт.

## 2. Окна и разрешения — только руками

Базис: DPI 100 %, разрешение 1920×1080. Затем матрица:

- [ ] 1366×720 @ 100 DPI
- [ ] 1366×768 @ 100 DPI
- [ ] 1920×1080 @ 125 DPI
- [ ] 3840×2160 @ 150 DPI

На каждом: элементы не наезжают друг на друга, текст не обрезан, окно не вылезает за экран.
Наши окна: desktop **1100×680** (минимум 860×520), in_game **340×620** (минимум 340×180),
dynamo_warning **400×150**.

- [ ] **Fullscreen и windowed.** Запустить Deadlock, проверить оверлей в полноэкранном режиме,
      затем переключить игру в оконный и убедиться, что всё на местах.
- [ ] **Alt+Tab.** Свернуть игру или переключиться — **ни одно окно приложения не должно
      оставаться на экране**. Overwolf показывает оверлеи только когда игра в фокусе.
- [ ] **Второй экран** (гайд требует отдельно). Вывести приложение на второй монитор, игра — на
      первом.

## 3. Оверлей в игре — только руками

- [ ] Открыть оверлей хоткеем, убедиться, что он отрисовался корректно.
- [ ] **Проверить новую позицию:** 20 px слева, 80 px сверху. Раньше она не применялась.
- [ ] Общая функциональность в игре: маршрут закупок, следующий предмет, таймеры.
- [ ] **Клик-сквозь.** Нажать на места, где клик ушёл бы в игру (меню, способности) — клик должен
      попадать в приложение и **не** в игру.
- [ ] **Ссылки.** Любая ссылка внутри игры открывается в браузере Overwolf либо, если в системном,
      пользователю сказано об этом. У нас все внешние ссылки идут через `ui.openExternal()`.

## 7. Производительность — частично

- [ ] **Утечки памяти.** Память должна расти и падать. Если после роста не возвращается — утечка.
      Смотреть в диспетчере задач Overwolf и в Windows Task Manager.
- [ ] **Всплески** CPU, памяти и сети — в Windows Task Manager.
- [ ] **Размер иконки в доке** — 256×256, PNG, < 30 КБ ✅ (проверено)
- [ ] **Оффлайн.** Запуск без сети: приложение должно сказать пользователю, что данных нет, а не
      молчать пустым экраном.
